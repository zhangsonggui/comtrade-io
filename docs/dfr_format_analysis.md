# 689D2000.DFR (ЭКРА БЭ2704) 格式分析报告

## 概述

`689D2000.DFR` 是俄罗斯 ЭКРА 公司 БЭ2704 系列数字式保护装置输出的故障录波文件。该目录下有三份文件，描绘同一份故障数据（AT2变压器保护动作，三侧电流电压）的三种不同格式：

- **689D2000.DFR** — 俄罗斯 ЭКРА БЭ2704 原生二进制格式（.DFR 单文件）
- **689D2000.DFR.comtrade_ASCII.cff** — 标准 IEEE 60255-24:2013 CFF 文本格式
- **689D2000.DFR.comtrade_BINARY.cff** — 标准 IEEE 60255-24:2013 CFF 二进制格式

## 文件结构详解

### 1. [WNDR] 段（文本配置）

起始偏移 `0x0000`，长度 `4088 字节`，编码 `CP1251`（俄语 Windows）。

#### 第1行：段标记
```
[WNDR]
```

#### 第2行：站名与设备
```
DFR:  "защита АТ2,Цифровые защиты,50689",50689
CFG:  защита АТ2_Цифровые защиты_50689,50689,2013
```
- DFR 第1个引号内为站名全称，逗号分隔各部分；COMTRADE 用下划线连接
- DFR 无版本年份；COMTRADE 补充 `2013` (IEC 60255-24:2013)

#### 第3行：通道计数
```
84,32A,52D
```
**完全一致**

#### 模拟通道定义（4~35行）

DFR 格式字段：

| 序号 | 字段 | 示例 | 说明 |
|------|------|------|------|
| 1 | 序号 | `1` | 通道索引 |
| 2 | 通道名称 | `"Ia-N1"` | 带引号 |
| 3 | 相别代码 | `с` | `с`/`в`/`а` = A/B/C相 |
| 4 | 监测回路 | `А` | `А`=高压侧, `С`=中压侧, `Н`=低压侧 |
| 5 | 满度值 | `6.90479` | 对应满量程物理值 |
| 6 | 转换系数 | `0.0034523` | 数字量→物理量系数 (a) |
| 7 | 单位字符串 | `"I-N1"` | 通道类型标识 |
| 8 | 相别(重复) | `A` | 标准相别字母 |
| 9~11 | 保留字段 | ` ` | 空格填充 |
| 12 | 通道类型 | `1` | `1`=电流, `100`=电压 |
| 13 | 一次额定值 | `2000` | CT/PT 一次值 |
| 14 | (可能为空) | ` ` | 尾部 |

**到 COMTRADE CFG 的映射：**

```
COMTRADE: idx,ch_id,ph,ccbm,unit,a,offset,delay,min,max,primary,secondary,PS
DFR:      idx,name, 相,回路,  unit, a,  ,     ,   ,   ,prim,  类型, 87
                                                     ↑     ↑
                                                  fields[13] fields[12]
```

- **unit** ← fields[6] 单位字符串（如 `"I-N1"` → `A`）
- **a** (multiplier) ← fields[5] 转换系数
- **offset** = 0 (DFR 无通道独立偏置)
- **delay** = 0
- **min/max** = 0 (DFR 无通道量程)
- **primary** ← fields[13] 一次额定值
- **secondary** ← fields[12] 通道类型 (1→1A, 100→100V)
- **PS** = S (默认二次侧)

#### 数字通道定义（36~87行）

```
DFR:  81,"81 ПО Iд.A> ДЗТ Т"
CFG:  1,81 ПО Iд.A> ДЗТ Т,,,0
```

- DFR 使用**保护装置原始编号** (81~223) 作为每行序号
- COMTRADE 对数字通道**重新编号为 1~52**
- 通道名称内容一致

#### 尾部参数（88~91行）

```
32768        ← 零偏中点值（int16 有符号→无符号转换用）
24           ← 每周波采样点数
12612        ← 总采样点数
(空白行)     ← 空行/填充
```

### 2. [Data] 段（二进制数据）

#### 标记与设备ID
```
[Data]\r\n        ← 段标记，偏移 4088
2704V042\r\n      ← 装置型号 + 固件版本
```

- `2704` = БЭ2704 装置型号
- `V042` = 固件版本号

#### 二进制头（~248 字节）

偏移 `4105~4351`（含设备 ID 行后的 248 字节），包含装置运行参数和配置信息，格式因装置型号而异。

#### 采样数据帧（偏移 4352 起）

每帧 72 字节：

```
┌──────────────────────────────────────┬──────────────────────────┐
│ 32 个模拟通道 (每通道2字节有符号LE)  │ 4个字数字状态 (uint16 LE) │
│ = 64 字节                           │ = 8 字节                │
└──────────────────────────────────────┴──────────────────────────┘
```

**与 COMTRADE BINARY 帧的区别：**

| 特性 | COMTRADE BINARY (80B) | DFR (72B) |
|------|----------------------|-----------|
| 采样序号 | 4字节 uint32 | 不存储（隐含） |
| 时间戳 | 4字节 uint32 | 不存储（可推算） |
| 模拟数据 | 32×2B int16 = 64B | 32×2B int16 = 64B |
| 数字状态 | 4×2B uint16 = 8B | 4×2B uint16 = 8B |
| 每帧大小 | 80 字节 | 72 字节 |

时间戳恢复：`timestamp[n] = n × (1,000,000 / 采样率)`，采样率从 WNDR 中的周波采样点数 × 工频频率得出。

#### 数字通道状态打包

52 个数字通道打包在 4 个 uint16 字中（共 64 位，足够容纳 52 位）：

```
Word 0: 位0~15 → 数字通道 1~16
Word 1: 位0~15 → 数字通道 17~32
Word 2: 位0~15 → 数字通道 33~48
Word 3: 位0~7  → 数字通道 49~52（高位未使用）
```

## 已知的设备型号差异

不同的 ЭКРА 装置可能产生不同结构的 DFR 文件：

| 型号 | 二进制头大小 | 备注 |
|------|-------------|------|
| БЭ2704 V042 | ~248 字节 | 本次分析对象 |
| 其他型号 | 待补充 | 可通过 [Data] 后的型号字符串识别 |

建议的识别策略：读取 `[Data]\r\n` 后的型号字符串，根据型号查找对应的二进制头大小。

## 转换精度分析

比较 DFR 和 COMTRADE 中的转换系数：

| 通道 | DFR 系数 | COMTRADE 系数 | 精度损失 |
|------|---------|---------------|---------|
| Ia-N1 | 0.0034523 | 0.00345222238888056 | ~6位有效数字 |
| ВН-Uab | 0.00707054 | 0.00707032 | ~5位有效数字 |

DFR 存储的转换系数精度较低（6-7位有效数字 vs COMTRADE 的 15 位），这是由 DFR 文本格式的字段宽度限制导致的。
